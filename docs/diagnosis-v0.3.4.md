# v0.3.4 启动与兼容性排查

## 已确认的问题

旧 BAT 在 PowerShell 启动后直接退出，缺少入口兜底。安装脚本加载配套文件、解析数据路径等步骤位于主 try/catch 之前。前次隔离测试中，缺少主脚本约 0.7 秒退出、缺少配套脚本约 1.9 秒退出，都没有诊断文件或原定的 30 秒提示。

用户确认完整解压后运行，因此上述缺失场景只证明工具的错误提示缺口，不证明故障电脑发生了文件缺失。系统若根本没有执行 BAT，安装器日志无法生成；新增 VBS 备用入口可绕开 BAT 文件关联，但仍受 Windows 脚本策略约束。

截图是状态检查输出，已存在中文兼容副本，没有显示安装失败。其“官方有翻译开关”和“版本不同”提示不能证明补丁无效。旧状态检查没有验证副本来源哈希或补丁哈希，也未识别同路径更新导致的过期副本。

## 新版改动

- BAT 使用 Windows PowerShell 完整路径，关闭延迟展开，避免 CALL 对路径再次展开。
- 独立 bootstrap 进程检查文件、保存完整启动输出，覆盖子进程解析错误、初始化错误和运行错误。BAT 失败后保留窗口。
- 日志目录不可写时尝试临时目录；PowerShell 本身的启动错误有单独日志。
- 新增 install-fallback.vbs，直接运行 bootstrap；备用入口失败弹窗。
- 支持显式拖入程序或文件夹；无 Store 安装时发现当前会话正在运行、且具有所需中文资源的自定义安装。
- 状态报告新增 localizationReady、compatibleCopyCurrent、compatibleCopyPatched、compatibleCopyLauncherReady；保留 ready 的原有资源可用性含义。
- 对副本源文件、已修补资源和可执行文件校验哈希；提示官方窗口仍在运行、上次启动失败、同路径更新和缺失启动器。

## 真实新版验证

本机安装包 `26.911.7940.0`、应用 `26.911.61220` 与用户截图一致。实际两处语言开关仍匹配原来的安全补丁模式，无需放宽匹配规则。

更新测试中绑定的压缩符号名后，对真实界面组件执行远程 enable_i18n=false 的对照：原组件不加载中文，修补组件加载中文。校验改动资源、分块和模拟 EXE 哈希；其余资源和官方 ASAR 保持不变。

真实隔离副本启动测试通过：不修改用户原配置、不终止正在使用的官方应用，副本持续运行，重复启动复用原进程。

## 边界

新增启动回归覆盖缺失主脚本、脚本语法错误、运行错误、成功返回，以及包含空格、方括号、`&`、`%PATH%`、`!` 的路径。失败 BAT 在标准输入保持打开且不发送按键时仍保持运行，确认后返回非零退出码。正常入口仍自动完成。

工作流回归新增同一路径原程序内容变化的场景，确认状态报告将旧副本标记为过期。旧式长路径、配置保护、启动器进程边界、自定义运行目录发现测试通过。发布包 24 个文件 SHA-256 与源码逐项一致。

界面组件测试控制外部依赖，运行测试检查进程和独立用户目录，不是全部页面视觉验收。旧式长路径测试模拟 Windows PowerShell 5.1 的路径处理规则，不是新一轮 Win10 实机测试。
